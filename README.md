# solar-interconnection-ieee14bus
Solar PV interconnection load flow study on the IEEE 14-bus test system using PSS/E v33.4. Includes base case, solar case, results and report.
> **Note:** `.sav` and `.sld` files require PSS/E v33.4 to open.
> A PNG export of the single line diagram is available in the
> `results/` folder for viewing without PSS/E.
